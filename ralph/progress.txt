# DI Manager v2.0 Runtime Container - Progress Log

## Codebase Patterns
- TypeScript 5.0+ with strict type checking
- ESM imports require explicit .js extensions (moduleResolution: nodenext)
- Prettier formatting: multiline unions broken across lines with leading |
- All types exported from src/types.ts, re-exported via src/index.ts
- Test files: tests/unit/src/*.spec.ts with vitest
- Type-level tests use `undefined as unknown as Type` pattern for type verification
- Unused variables must start with _ prefix to pass ESLint
- Runtime container implementation uses Map-based registry for O(1) lookups
- Arrow functions used in test setup must be declared in outer scope per ESLint rules
